# Scientific prose style guide

## Priority order

Accuracy > inferential calibration > clarity > concision > elegance.

Never sacrifice a necessary boundary or qualifier merely to shorten a sentence.

## Sentence principles

- Put the main actor near the subject and the main action in the verb.
- Prefer `we analyzed` to `an analysis was conducted`, unless actorless phrasing serves a real purpose.
- Keep old/contextual information before new/emphatic information when possible.
- Keep subject and verb close; move long conditions after the main clause or into a preceding sentence.
- Use one main claim per sentence. A sentence may be long when its logical structure remains visible.
- Make pronoun referents explicit, especially `this`, `it`, `they`, and `which`.
- Use parallel grammar for parallel concepts.

## Paragraph principles

- One paragraph, one argumentative function.
- First sentence: orient or claim; middle: evidence/reasoning; final sentence: consequence or transition.
- Avoid citation-led paragraphs and strings of study summaries.
- Delete sentences that only announce obvious structure (`It is important to note that...`).

## Concision replacements

| Avoid when unnecessary | Prefer |
|---|---|
| utilize | use |
| in order to | to |
| due to the fact that | because |
| a number of | several / give the number |
| has the ability to | can |
| it is worth noting that | delete; state the point |
| the present study | this study / we |
| conducted an examination of | examined |
| provides evidence demonstrating | shows / provides evidence that |
| plays a crucial role | specify the relation |
| novel / innovative / groundbreaking | state what is new and useful |
| robust | name the robustness test or delete |

## Calibration ladder

Strongest claims require the strongest design.

`causes` > `changes` > `predicts` > `is associated with` > `is consistent with` > `suggests`.

Do not use a weaker-looking hedge to disguise an unsupported claim. Fix the proposition itself.

## Numbers and statistics

- Preserve signs, decimals, denominators, units, labels, and uncertainty.
- Use participant `N` for people and describe repeated rows as observations.
- Pair effect sizes with confidence/credible intervals when available.
- Use exact `p` values above .001 and `p < .001` below .001 under current journal guidance.
- Avoid `trend toward significance`, `marginally significant`, and binary supported/unsupported language when estimates and uncertainty tell a clearer story.

## Accessibility

- Define necessary technical terms once in plain language.
- Prefer a short concrete example over a second abstract definition.
- Keep standard field terms when substitution would reduce precision.
- Do not vary terms for stylistic variety when they denote the same construct.
