# Worklog

> **TEMPLATE — FILL THE STATE BLOCK, THEN APPEND AS YOU GO.**
> Read the state block first, every session, before touching anything else.

Process state, not evidence state. Verified numbers live in `evidence-ledger.md`; claim
wording lives in `claim-risks.md`. This file records **where the project is and why it got
here** — the decisions that would otherwise be re-litigated every session.

Run `python scripts/worklog.py status` to see the state block plus a staleness check.
Run `python scripts/worklog.py add` to append a dated entry without hand-formatting it.
